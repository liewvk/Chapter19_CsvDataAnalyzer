# Chapter19_CsvDataAnalyzer

A C++ application for analyzing CSV data files.

## Overview

This project provides tools for reading, parsing, and analyzing CSV (Comma-Separated Values) data files. Built with modern C++ and CMake for cross-platform compilation.

## Technologies

- **Language**: C++ (98.2%)
- **Build System**: CMake (1.8%)

## Getting Started

### Prerequisites

- C++ compiler (C++11 or later)
- CMake 3.10 or higher

### Building the Project

```bash
mkdir build
cd build
cmake ..
make
```

## Usage

Run the compiled executable to analyze CSV files:

```bash
./CsvDataAnalyzer <input_file.csv>
```

## Features

- Parse and read CSV data files
- Perform data analysis operations
- Cross-platform compatibility

## Project Structure

- `src/` - Source code files
- `CMakeLists.txt` - CMake build configuration
